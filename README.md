# Internship Posting Descriptive Analysis

## Executive Summary

This project evaluates student engagement with internship and job postings in the Knowlton Center's Spring 2026 career newsletters to identify opportunities to improve content selection, placement, and presentation.

I found that **featured postings generally attract more clicks**, with engagement declining most noticeably after the first five positions. Employer recognition influences clicks in select communities, while shorter descriptions perform significantly better only in Exploration community. Based on these findings, I recommend **prioritizing high-value postings in the top positions, expanding featured postings where effective, and tailoring content strategies to each career community** rather than applying a uniform approach.

I analyzed clicks per posting across seven career communities using descriptive statistics and negative binomial regression. I examined four primary factors: featured status, posting position, employer recognition, and description length, while controlling for other relevant posting characteristics to better isolate their associations with engagement.
